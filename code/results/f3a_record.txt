F3a -- cross-robot disagreement as a drift signal. Pre-registered feasibility screen for route R3.
generated 2026-10-23; 12 runs (clean and drift, 6 seeds), N=3 mesh, planner certified, budget 100 m, K=120.
regenerate with: python experiments/f3a_crossrobot.py 4 ; python experiments/f3a_analysis.py

HYPOTHESIS. E50 showed the self-estimated label-error rate p_hat separates a drifting robot from its clean
teammates by 1.44x, against 1.43x on a clean team: a uniformly displaced map contradicts nothing locally, so
the detector is blind to exactly the fault the certificate is blind to. Drift should be visible only relative
to another robot's frame.

MEASURE. Each robot's own single-robot certificate commits a label where exactly one of its two e-values
clears 1/alpha. For a pair, the denominator is the cells where both gates are open and both robots commit;
the numerator is those where the committed labels differ.

RULE, fixed in advance. R3 feasible if the drifting pair's disagreement exceeds the clean pair's by >= 3x.

VERDICT: PASS by 6x on the pre-registered threshold.

ATTRIBUTION (not asked for by the screen). In every drifting pair the disagreeing cells are the drifter's
wrong ones: the clean member's error on the shared cells is 0.000-0.005 while the drifter's is 0.001-0.074.
So the signal names which robot is at fault, not only that a pair conflicts.

At seed 4 the drifting robot's realized error (0.0018) is below both teammates', so there was no fault to
detect and the signal correctly reported none. Spearman correlation between the drifter's realized error and
the pair disagreement is 0.829 over the six seeds: the signal tracks fault magnitude rather than the injected
label.

CAVEAT for the follow-up. These runs share one grid, so no relative-pose estimate is needed to compare maps.
A field system must either co-register or treat the frame offset as a nuisance parameter; this screen
establishes that the label signal exists, not that it survives unknown relative pose.
